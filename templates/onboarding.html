Hướng Dẫn Lấy API Token (Atlassian Jira)

1

Truy cập trang quản lý Token

Mở trang chính thức của Atlassian để quản lý API Token.

Mở trang API Tokens
2

Đăng nhập

Hệ thống sẽ yêu cầu Đăng nhập. Hãy thực hiện đăng nhập vào tài khoản cần sử dụng.

3

Nhấn nút “Create API token”

Trong trang API Tokens, chọn Create API token. Hãy đặt tên dễ nhớ, ví dụ như “Smart Backlog Assistant”.

4

Dán token vào hệ thống

Sau khi token được tạo, hãy nhấn Copy. Lưu ý: Atlassian sẽ không cho xem lại token sau khi rời trang! Quay lại trang cấu hình, dán API Token vào ô API Token
